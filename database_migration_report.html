1. Previous Issues & Limitations

1. Multi-Device Data Reset Bug (Race Condition / State Overwrite)

Entering data on one PC and then accessing from another device or mobile immediately cleared and wiped system data, because the new device had empty local state and posted default empty state to the server.

2. Absence of Dedicated Cloud Database

The system lacked a dedicated cloud database and relied only on browser local storage and local JSON file, posing risks for multi-terminal restaurant operations.

3. 48 JSX Tag Type Errors in VS Code

Missing @types/react and @types/react-dom caused TS errors under all HTML tags in the editor.

4. Local ISP DNS Resolution Blocking (querySrv ECONNREFUSED)

Certain local ISP DNS servers failed to resolve MongoDB Atlas SRV records.
