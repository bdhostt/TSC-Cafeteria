কীভাবে ইনস্টল করবেন (বাংলা নির্দেশিকা):
--------------------------------------------------------------------
১. এই জিপ (ZIP) ফাইলের সব ফাইল যেকোনো একটি ফোল্ডারে Extract (Unzip) করুন।
২. "INSTALL-POS-PRINTER.bat" ফাইলটিতে ডাবল ক্লিক করুন।
৩. ইনস্টলার নিজে থেকেই:
   - আপনার ডেস্কটপে "POS Printer Agent" নামের শর্টকাট বানিয়ে দিবে।
   - উইন্ডোজ স্টার্টআপে রেজিস্টার করবে (পিসি রিস্টার্ট হলেও প্রিন্টার সচল থাকবে)।
   - সাথে সাথে ব্যাকগ্রাউন্ডে সাইলেন্ট মোডে প্রিন্টার ব্রিজ চালু করে দিবে।
৪. সফটওয়্যার ওয়েবসাইটে গেলে স্বয়ংক্রিয়ভাবে "🟢 Printer Bridge Online" দেখতে পাবেন!

--------------------------------------------------------------------
How to Install (English Instructions):
--------------------------------------------------------------------
1. Extract all files from this ZIP package.
2. Double click "INSTALL-POS-PRINTER.bat".
3. The installer will automatically:
   - Create a desktop shortcut "POS Printer Agent"
   - Register auto-start on Windows startup
   - Start the print bridge silently in the background
4. Open the POS website to see "🟢 Printer Bridge Online" instantly!
